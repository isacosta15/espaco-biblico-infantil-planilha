Crie uma plataforma web completa chamada “Espaço Bíblico Infantil”.

OBJETIVO:
A plataforma será utilizada no departamento infantil da igreja para:
- cadastrar crianças,
- controlar presença,
- acompanhar frequência,
- visualizar relatórios por data,
- gerar estatísticas automáticas,
- e funcionar totalmente OFFLINE também.

========================================
REQUISITO MAIS IMPORTANTE
========================================

A plataforma PRECISA funcionar sem internet/Wi-Fi.

Ela deve funcionar como PWA (Progressive Web App), permitindo:

- funcionamento offline,
- cache automático,
- armazenamento local,
- sincronização futura quando internet voltar.

Mesmo offline deve ser possível:
- pesquisar crianças,
- cadastrar crianças,
- marcar presença,
- visualizar histórico,
- visualizar dashboard,
- acessar relatórios anteriores.

Utilizar:
- Service Worker
- IndexedDB
- Cache inteligente
- Sincronização automática

========================================
3. CADASTRO DE CRIANÇAS
========================================

Campos obrigatórios:
- Nome completo
- Data de nascimento
- Sexo (Menino/Menina)
- Nome do responsável
- Telefone do responsável
- Comum/congregação

Campos opcionais:
- Restrição alimentar
- Descrição da restrição
- Possui TEA/autismo
- Observações

REGRAS:
- A idade NÃO deve ser salva no banco.
- A idade deve ser calculada automaticamente usando a data de nascimento.
- A idade deve atualizar automaticamente com o tempo.

CRIANÇAS COM 12 ANOS OU MAIS:
Destacar visualmente:
- borda amarela
- badge “⚠️ 12+”
- ou ícone especial.

========================================
4. SISTEMA DE PRESENÇA
========================================

IMPORTANTE:
NÃO criar lista de chamada tradicional.

FUNCIONAMENTO:
- Deve existir uma tela de presença dinâmica.
- O usuário pesquisa uma criança pelo nome.
- A pesquisa deve ser instantânea.

Exemplo:

Pesquisar:
“Ana”

Resultados:
- Ana Clara
- Ana Júlia

Cada resultado deve possuir:
[Marcar presença]

Ao clicar:
- salvar presença automaticamente,
- salvar data,
- salvar horário,
- mudar botão para verde,
- impedir presença duplicada no mesmo dia.

========================================
5. CRIANÇA NÃO ENCONTRADA

7. HISTÓRICO POR DATA
========================================

- Meninos: 10
- Total: 25

09/05/2026
- Meninas: 18
- Meninos: 12
- Total: 30

O usuário deve conseguir abrir qualquer data anterior.

Exemplo:

E visualizar:

- total de meninos,
- total geral,
- lista de presentes daquele dia.
